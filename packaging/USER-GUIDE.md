# 모아컷 v0.2.0 · Windows 10/11 64비트

## 설치와 업데이트
1. **MOACUT-Setup-0.2.0-Windows-x64.exe 하나를 다운로드해 실행**합니다. Python 설치나 API 키는 필요하지 않습니다.
2. 이전 모아컷이 실행 중이면 작업 표시줄의 모아컷 아이콘에서 ‘모아컷 종료’를 선택한 뒤 설치합니다. 기존 프로그램 위치에 업데이트하며, 사진과 작업 기록은 별도 데이터 폴더에 보존합니다.
3. 설치 후 **바탕화면 또는 시작 메뉴의 ‘모아컷’**으로 실행합니다. 기존 브라우저 탭 대신 새로 열린 화면을 사용하세요.

## 촬영부터 저장까지
1. 오늘 새 작업 또는 기존 작업 이어하기를 선택합니다. 같은 작업 안에서 여러 브랜드를 섞어 촬영할 수 있습니다.
2. 읽어줄 촬영 항목을 선택/직접 입력해 저장합니다. 브랜드는 아직 입력하지 않습니다.
3. 카메라 연결 → 촬영 영역 지정 → 손과 상품을 치우고 빈 배경 등록 → 자동 촬영 시작을 누릅니다.
4. 한 상품당 4컷을 저장하면 다음 상품으로 자동 전환합니다. 필요하면 직접 한 컷으로 라벨·상세를 촬영합니다.
5. 사진 확인에서 상품을 선택한 뒤 왼쪽 패널에 브랜드를 입력해 적용합니다. 적용에 성공하면 선택 상자가 해제됩니다. 실패하면 선택을 유지합니다.
6. 사진과 브랜드를 확인한 뒤 ‘선택 상품 검토 완료’ 또는 **‘전체 상품 검토 완료’**를 누릅니다. 전체 검토는 브랜드 지정·미검토·저장할 사진이 있는 상품을 대상으로 합니다. 미지정/삭제/전부 제외 상품은 건너뜁니다.
7. 전체 검토 후 ‘예 · 폴더 저장으로’는 저장 화면으로 이동하고, ‘아니요’ 또는 Esc는 현재 화면과 검토 상태를 유지합니다. 이동만으로 파일을 저장하지는 않습니다.
8. 저장 위치를 확인하고 **‘폴더로 저장’**을 누릅니다. 검토한 사진을 브랜드/상품별 폴더로 복사합니다. 저장 대상이 없으면 이유와 검토 화면으로 돌아가는 버튼이 표시됩니다. 저장 중/완료 경로/오류는 버튼 근처에서 확인할 수 있습니다.

왼쪽 브랜드·검토 패널은 넓은 화면에서 고정되며 상품 목록을 내리면서 사용할 수 있습니다. 좁은 화면에서는 위로 배치됩니다. 브랜드 자동 인식 기능은 아니며 브랜드는 사용자가 지정합니다. 사진 삭제는 복구 가능한 휴지통이며 원본 영구 삭제나 이미 내보낸 복사본 삭제를 수행하지 않습니다. 같은 폴더 구조의 ZIP도 받을 수 있습니다.

## 저장이 안 될 때
- 브랜드를 지정했어도 **검토 완료**를 누르지 않았다면 저장되지 않습니다. 사진을 확인하고 전체/선택 검토를 완료하세요.
- 브랜드 미지정 상품은 브랜드부터 지정합니다. 제외/삭제한 사진은 저장 대상에서 빠집니다.
- 저장 폴더가 사라졌거나 쓰기 권한이 없으면 다른 폴더를 선택하세요. 다시 저장하면 새 결과 폴더가 생성됩니다.

## 데이터와 종료
사진·작업 기록은 **%LOCALAPPDATA%\MOACUT\captures**, 프로그램은 **%LOCALAPPDATA%\Programs\MOACUT**에 있습니다. 업데이트/프로그램 제거는 사용자 데이터와 비추적 출력 파일을 삭제하지 않습니다. 백업할 때 captures 전체(session.json, work-sessions, 사진 포함)와 별도 결과 폴더를 복사하세요. 개발 폴더의 기존 사진을 자동 이관하지는 않습니다.

브라우저를 닫아도 프로그램은 남아 있습니다. 작업 표시줄 오른쪽의 모아컷 아이콘에서 종료합니다. 날짜가 바뀌면 오늘 새 작업을 시작하고, 지난 작업은 검토/복원/저장만 가능합니다.

## 장비와 실행 확인
사용 가능한 NVIDIA GPU를 자동 선택하고 없거나 실패하면 CPU로 전환합니다. CPU는 더 오래 기다릴 수 있습니다. 0.65초는 움직임 안정 기준이며 인식 대기를 포함한 총 촬영 시간은 아닙니다. 실제 속도와 촬영 품질은 카메라/PC/상품에서 확인해야 합니다.

USB 카메라와 Windows 한국어 음성이 필요합니다. 다른 앱이 카메라를 사용하면 연결되지 않을 수 있습니다. **환경점검.cmd**는 사용자 사진이나 카메라를 열지 않고 모델/GPU·CPU/음성을 점검합니다. 결과는 %LOCALAPPDATA%\MOACUT\diagnostics.json, 로그는 logs에 저장합니다. 유료 API/사진 외부 전송은 없습니다.

실행 파일은 코드서명이 없습니다. Windows 보호 알림이 나오면 출처와 제공된 SHA256을 확인하고 조직 정책에 따라 처리하세요. 설치기는 Inno Setup 6.4.3을 사용합니다(https://jrsoftware.org/).
