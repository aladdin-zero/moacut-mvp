# 모아컷 1차 MVP · Windows 10/11 64비트

1. Release의 모든 part ZIP과 Install-MOACUT.cmd를 같은 폴더에 받고 Install-MOACUT.cmd를 실행합니다. 다운로드 확인 후 자동으로 압축을 풉니다. 직접 풀 때도 모든 ZIP을 같은 폴더에 풀어야 합니다. ZIP 안에서 바로 실행하지 마세요.
2. **MOACUT.exe**를 실행하면 기본 웹 브라우저에 촬영 화면이 열립니다. Python 설치나 API 키는 필요하지 않습니다.
3. 오늘 새 작업 또는 기존 작업 이어하기를 고릅니다.
4. 브랜드를 적용하고 음성으로 읽을 촬영 항목을 선택/직접 입력해 저장합니다.
5. 촬영 화면에서 카메라 연결 → 상품과 손이 없는 빈 배경 등록 → 자동 촬영 시작을 누릅니다.
6. 한 상품당 4컷 저장 뒤 다음 상품으로 자동 전환합니다. 사진 확인에서 삭제/복원·합치기/나누기·검토 완료를 진행합니다.
7. 저장할 폴더를 선택하고 ‘폴더로 저장’을 누릅니다. 검토 완료 사진만 브랜드/상품별로 복사합니다.

## 그래픽카드와 속도
사용 가능한 NVIDIA GPU를 자동 확인하며, GPU 사용에 실패하거나 GPU가 없으면 CPU로 전환합니다. 촬영 화면에 GPU/CPU와 인식 소요 시간이 표시됩니다. CPU는 사진을 뒤집은 뒤 더 오래 멈춰 있어야 할 수 있습니다. 추론 중 화면이 바뀐 결과로는 자동 촬영하지 않습니다. 0.65초는 움직임 안정 기준이며 총 촬영 대기시간이 아닙니다.

현재 검증 장비는 Windows 64비트 / NVIDIA RTX 3070 8GB입니다. CPU 경로도 합성 영상으로 확인하며 실제 직원 작업속도는 별도 현장 확인이 필요합니다. USB 카메라가 필요하고, 다른 앱에서 카메라를 사용 중이면 연결되지 않을 수 있습니다. 첫 인식기 준비에는 시간이 걸립니다. 한국어 음성이 없으면 Windows 설정의 한국어 음성 기능을 추가하세요. 유료 API나 사진의 외부 전송은 사용하지 않습니다.

## 종료와 데이터 보관
- 브라우저를 닫아도 촬영 프로그램은 남아 있습니다. Windows 작업 표시줄 오른쪽 숨겨진 아이콘에서 **모아컷 → 모아컷 종료**를 선택합니다.
- 사진과 작업 기록은 **%LOCALAPPDATA%\MOACUT\captures**에 저장합니다. 프로그램 폴더와 별도이므로 업데이트해도 남습니다. 작업 표시줄 아이콘의 ‘작업 데이터 폴더’에서 열 수 있습니다.
- 백업할 때 captures 폴더 전체를 복사하세요. session.json과 work-sessions 폴더, 사진 UUID 파일이 모두 필요합니다. 결과 저장 폴더도 별도로 백업하세요.
- 날짜가 바뀌면 오늘 새 작업을 시작합니다. 지난 작업은 사진 확인/복원/저장이 가능합니다. PC 날짜를 기준으로 합니다.
- 사진 삭제는 복원 가능한 휴지통이며 영구 삭제가 아닙니다. 이미 내보낸 복사본은 그대로 남습니다.
- 실행 문제는 **환경점검.cmd**로 확인합니다. 카메라나 사용자 사진을 열지 않고 모델/GPU/CPU/음성을 점검합니다. 결과는 %LOCALAPPDATA%\MOACUT\diagnostics.json, 실행 로그는 같은 폴더의 logs에 있습니다.

이 실행 파일은 1차 MVP이며 코드서명이 없습니다. OS에서 표시한 보호 경고는 배포자와 파일의 출처·해시를 확인한 뒤 조직의 정책에 따라 처리하세요. 프로그램이나 보안 설정을 자동 변경하지 않습니다.
