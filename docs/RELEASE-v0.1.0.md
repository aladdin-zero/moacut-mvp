# v0.1.0 · 1차 MVP

Windows 10/11 64비트용 첫 클라이언트 전달본입니다.

- 촬영 항목 선택/직접 입력/추가·삭제와 로컬 한국어 음성 안내
- 상품당4컷 자동 묶음, 사진 삭제/휴지통 복원·검토 후 브랜드/상품 폴더 저장
- 날짜별 작업 새로 시작/이어하기와 미완성 상품 복원
- 사용 가능한 NVIDIA GPU 자동 선택, 실패/미지원 시 CPU 전환
- Python 설치가 필요 없는 실행 환경과 오프라인 OWLv2 모델 포함
- 작업 데이터는 %LOCALAPPDATA%\MOACUT에 별도 보관, 실행/종료는 MOACUT.exe와 작업 표시줄 아이콘 사용

개발 회귀 Python45개/JavaScript5개 및 문법 검사 통과. 배포본 자체의 격리 실행기 시작/종료·GPU/강제CPU·한국어 음성을 확인했습니다. CPU 경로는 느린 추론 중 화면이 바뀐 결과를 버리고, 화면이 계속 유지된 결과만 사용합니다. 추론 완료 후에도 기존0.75초 만료/화면일치/연속인식 조건을 확인합니다.

합성 입력에서 RTX3070 약0.24초/CPU 약3.3초(각워밍업후1회)로 확인했습니다. 실제 상품 정확도·현장 노동시간·모든 PC 드라이버를 검증한 결과는 아닙니다. CPU는 두번연속인식/안정조건으로 실제컷당대기시간이 더 길 수 있습니다. 코드서명은 포함하지 않았습니다.

사용 방법: 모든 part ZIP과 Install-MOACUT.cmd를 같은 폴더에 다운로드 → Install-MOACUT.cmd 실행. 각 ZIP은 GitHub의2GiB제한 미만이며 설치기가 전체 해시를 확인하고 자동 압축 해제합니다. 세부 사항은 [사용 안내](../packaging/USER-GUIDE.md). 개발용 원본사진·API키·작업이력은 포함하지 않습니다. 이전 누적사진 자동재분류와 원본영구삭제는 제공하지 않습니다.
