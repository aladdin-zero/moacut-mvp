# v0.1.1 · 설치 파일 하나로 실행

**MOACUT-Setup-0.1.1-Windows-x64.exe 파일 하나만 받아 실행하세요.**

1. Windows 설치 파일을 다운로드하고 실행합니다.
2. 설치를 마치면 바탕화면 또는 시작 메뉴의 **모아컷**을 누릅니다.
3. 촬영 화면이 열리면 오늘 작업을 선택하고 카메라를 연결합니다.

ZIP 여러 개, 압축 해제, Install.cmd, Python 설치는 필요하지 않습니다. 기본 설치는 현재 사용자의 프로그램 폴더에 이루어지며 관리자 권한을 요청하지 않습니다. 제거는 Windows의 ‘설치된 앱’에서 진행합니다. 제거해도 사용자 사진/작업 기록(%LOCALAPPDATA%\MOACUT)은 보존합니다.

촬영 기능과 GPU 자동 감지/CPU 전환은 앱0.1.0과 같으며, 이번 버전은 설치·바로가기·제거 흐름을 개선했습니다. CPU는 느릴 수 있고 클라이언트의 실제 촬영속도/정확도는 현장 확인이 필요합니다. 실행 파일은 코드서명되지 않았습니다.
